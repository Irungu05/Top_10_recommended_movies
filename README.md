# Popularity-Based Movie Recommender System

## Overview
This repository contains data cleaning, exploratory analysis, sparsity evaluation, and a simple popularity baseline recommender for movie rating interaction data.

## Key Findings
- **Clean Interactions:** 500 valid ratings across 50 users and 24 movies.
- **Dataset Sparsity:** 58.33% empty user-item matrix cells.
- **Top Recommendation:** *Market Day* (M021) with an average rating of 4.47 (15 ratings).

## Files Included
- `DSA_4060_Week2_Movie_Ratings.csv`: Source dataset.
- `Movie_Recommendation_Analysis.ipynb`: Notebook with Markdown analysis and Python code.
- `top_10_recommended_movies.csv`: Exported top 10 recommended movies table.
